# Speed Up Music untuk Roblox

Website untuk mempercepat lagu (x1.5 / x2 / x3) dan menghasilkan MP3 di bawah 7 MB, siap upload ke Roblox. Bisa proses banyak lagu sekaligus (sampai 30). Semua proses berjalan di browser, tidak ada file yang diunggah ke server.

## Pakai
Buka halaman GitHub Pages repo ini, pilih lagu, pilih kecepatan, tekan **Proses semua**, lalu unduh.

## Deploy ke GitHub Pages
1. Upload `index.html` ke repo.
2. Settings → Pages → Source: `main` branch, folder `/ (root)`.
3. Tunggu 1-2 menit, website aktif di `https://USERNAME.github.io/NAMA-REPO/`.
